# homebrew-tap

[Homebrew](https://brew.sh) formulae for [Uranus-NetTools](https://github.com/JAEJUN090210/Uranus-NetTools).

```console
$ brew install jaejun090210/tap/unt
```

`brew upgrade` picks up new versions. The formula in `Formula/unt.rb` is updated automatically by the Uranus-NetTools release workflow; please do not edit it by hand.

macOS (Apple Silicon and Intel) and Linux (x64 and arm64) are supported.
